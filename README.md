# muc

هذا المستودع يحتوي توزيع الموقع الجاهز لـGitHub Pages. [تنزيل المصدر الكامل بمجلداته](muc-source.zip).

ملفا app.ts وbuild_content.py للقراءة المباشرة؛ لإعادة البناء فك muc-source.zip ثم نفّذ الخطوات أدناه داخل مجلد muc.


منصة دراسة على الهاتف بتجربة محادثات: مادة الشبكات ووحداتها، وحساب meorslan المعتمد داخل muc، والرسائل المحفوظة.

## المحتوى

نسخة مستقلة من networks-weekly-exams-ar: 42 ورقة جامعية تدريبية من40 علامة،1344 سؤالًا،109 مقاطع شرح و5 ملفات PDF أصلية. الوحدات كلها من مادة موضوعات خاصة في شبكات الحاسوب؛ لا تُضاف مواد أو معلومات منهجية خارج الملفات.

## التفاعلات

ضغط مطوّل/زر خيارات/قائمة سياق، تفاعلات وإيموجي، سحب للرد، اقتباس، نسخ، حفظ، تثبيت، تحويل، تحديد متعدد، تحرير الرسائل الشخصية وإخفاؤها مع التراجع. كلمات مفتاحية قابلة للضغط تعرض ربطًا متحركًا بالفكرة أو القانون. أسئلة داخل المحادثة، حالات بنماذج وتقييم ذاتي، وورقة امتحان مستقلة داخل عارض.

محادثات شخصية قابلة للإضافة، صور وملفات وملاحظات صوتية بإذن الميكروفون، إعدادات مظهر وحجم نص وحركة وخلفية، بحث وأرشيف، تصدير/استيراد التقدم، وتثبيت PWA وتنزيل المحتوى للمراجعة دون إنترنت.

التطبيق مساحة دراسة شخصية على الجهاز. لا يتصل بحسابات أو خوادم Telegram ولا يرسل رسائل لمستخدمين آخرين ولا يقدم مكالمات. meorslan حساب المنصة التعليمي؛ الشارة اعتماد داخل muc.

## المصدر والتشغيل

- TypeScript: واجهة التطبيق وتفاعلاته في src/app.ts.
- Python: تجهيز المحتوى والتحقق من نسخته المستقلة في tools/build_content.py.
- HTML/CSS: الواجهة والتصميم، وService Worker للمراجعة دون إنترنت.
- Node.js24 لتحويل TypeScript بأداة Node المضمنة، وPython3 لتجهيز المحتوى. لا حاجة لمكتبات تشغيل خارجية.

تشغيل بناء المصدر:

```sh
python3 tools/build_content.py
node tools/build.mjs
python3 -m http.server 8755 --directory dist
```

الاختبارات في tools/test.cjs وtools/advanced-test.cjs تستخدم Playwright وChrome. التسجيل الصوتي في الاختبار يستخدم ميكروفونًا اصطناعيًا داخل متصفح اختبار معزول.

الملفات الشخصية في IndexedDB. نسخة التقدم المصدرة تشمل الإجابات والنصوص والمحفوظات، ولا تنقل الملفات الصوتية أو المرفقات تلقائيًا. حفظ المرفقات منفصل، وإذن الميكروفون بيد المستخدم.

المظهر والحركات أعيد تنفيذهما للويب، بالاستفادة من نسخة Telegram-iOS المحلية كمرجع تفاعلي. لا يُستخدم شعار Telegram ولا كود Swift في واجهة الويب.
